# Beaver – Proyecto DAW G03

Plataforma web para contratar servicios a domicilio: el cliente elige un profesional, envía fotos del problema y recibe un presupuesto cerrado.

## Equipo
- Jheremy Ricky Brañez Siles – Coordinación y frontend
- Borja Argaiz Santolaya – Backend y base de datos
- Álvaro Torres González – Análisis, documentación y pruebas

## Tecnologías
HTML5, CSS3, JavaScript, PHP y MySQL (XAMPP en local).

## Estructura
- /css – hojas de estilo
- /js – scripts del cliente
- /public – páginas y recursos públicos
- /src – código PHP del servidor
- /sql – script de la base de datos
